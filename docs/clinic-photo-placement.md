## การเตรียมไฟล์

รัน `npm run images:prepare` เพื่อสร้างไฟล์ใหม่จากต้นฉบับ:

- แก้ทิศทางตาม EXIF ก่อนย่อขนาด และไม่คัดลอก metadata ของต้นฉบับ
- ภาพเปิดเว็บกว้าง 2400 พิกเซล ภาพอื่นกว้าง 1600 พิกเซล โดยคงสัดส่วน 4:3
- ใช้ WebP คุณภาพ 82 และ JPEG คุณภาพ 84 สำหรับตัวสร้างภาพแชร์ลิงก์
- แต่ละตำแหน่งใช้ `object-position` เลือกจุดสำคัญ โดยไม่ตัดไฟล์ต้นฉบับ
- ภาพเปิดเว็บปรับจุดครอปตามขนาดหน้าจอ ส่วนภาพเจ้าหน้าที่เน้นตำแหน่งบุคคลด้านขวา

การ์ดบริการใน SECTION III ทั้ง 11 รายการแสดงเฉพาะข้อมูลบริการ โดยไม่มีภาพ
และคำบรรยายใต้ภาพ ภาพห้องอัลตราซาวด์ยังใช้ในการ์ดจุดเด่นและข้อมูล SEO
โดยคำบรรยายภาพอธิบายสิ่งที่เห็นจริง

ภาพเก่าที่ไม่ได้อ้างอิงบนหน้าเว็บยังเก็บไว้ เพื่อไม่ลบทรัพยากรที่อาจใช้ในอนาคต
โลโก้ ไอคอนช่องทางติดต่อ และแผนที่คงเดิม
